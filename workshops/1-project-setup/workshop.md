# Astro Setup

Create an Astro project and understand its layout

## Instructions

Init your project with `npm create astro@latest`.

Astro projects typically organize parts of the website into folders. But it is completely up to you to decide how you will organize your code.

* `layouts/` for site-layout based components
* `components/` for all other components
* `utils/` for commonly used functions
* `pages/` for all page routes
* `pages/api/` to define http api endpoints
* `content/` for resources of Astro collections and `content.config.mts` e.g. blog posts

There is also a `public/` folder you can add static content.

Add a image of you to public, a short bio, and hello to get started with your site.
