# Icons Workshop

Icons are a core element of modern web design. They make interfaces intuitive, visual, and clean.

AI-generated websites often rely on generic emojis, professional websites use vector icons for crisp rendering, consistent styling, and brand identity.

## Instructions

1. The [Icons & SVG Guide](./icons.md) explains how SVGs work, how to style `fill` and `stroke`, and how to use interactive pseudo-classes (`:hover`, `:focus-within`).
2. Practice using SVGs by completing the [Social Links Deliverable](./social-links.md) to add interactive social icons to your website footer.
