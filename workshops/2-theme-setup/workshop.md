# Theme Setup

You should be intentional about your fonts, colors, and especially content of your website. It's what makes it yours.

This workshop dives into depth about adding fonts in Astro. It also includes additional resources for picking a color theme.

## Instructions

Some frameworks provide APIs to improve performance or better DX when adding fonts. Complete the [font workshop](workshops/2-theme-setup/fonts.md) to learn Astro's type-safe font API.
